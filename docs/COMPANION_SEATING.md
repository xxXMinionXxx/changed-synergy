# 伙伴乘坐

熟悉的朋友和羁绊可以使用玩家指定的座位。支持原版船、可乘坐矿车、Changed 办公椅／枕头，以及 Superb Warfare 的编号座位；其他模组可尝试通用乘客机制。

## 指定一只伙伴乘坐

1. 打开伙伴的关系轮盘，选择灰度马鞍加号图标“指定座位”。
2. 将准星对准载具或座椅，重新按下交互键确认。提示会显示目标名称；能确定容量时显示空位数，否则显示“尝试加入”。
3. 伙伴会正常靠近并登乘。选座等待最多十五秒，Esc 或打开其他界面可取消；途中可重新打开伙伴轮盘选择“取消乘坐”。

指定目标必须在玩家八格内、伙伴二十四格内，并通过服务端视线检查。上车任务最多二十秒，持续走不动会提前结束，不传送伙伴进车。

## 召集乘坐

玩家已经坐在多座载具上时，自身关系轮盘原来的结伴行动位置会显示“召集乘坐”。它招呼十六格内正在跟随自己的伙伴，包括符合条件的营地随行队；等待或工作中的成员不会被拉走。一次最多处理三十二只。

空位优先分给距离载具较近的伙伴。已知座位有临时预留，未知容量则逐只尝试正常登乘；真人仍可正常上车，不会被胶兽顶掉。最后以一条提示汇总成功和未能登乘的数量。

运输船（箱船）只有一个乘客位，玩家坐上后不能召集第二位。功能矿车不作为普通座位。Superb Warfare 的多座载具会给人类保留驾驶位，伙伴优先乘客位，不获得自动驾驶或车载武器操作能力。

## 下座与其他命令

伙伴已就座时，社交轮盘第一页会优先显示“下座”，包括通过其他方式登乘的可指挥伙伴。玩家下车后，也可以用自身关系轮盘的“结伴行动／Travel together”召回十六格内已就座的伙伴；即使它们原本已设为跟随，也会下座后继续跟随。只有载具停稳且附近有安全落脚点时才下座；没有安全位置则等待，稍后再尝试，避免从高空、岩浆或危险地面上方被抛下。

手动指定的座位会让伙伴继续坐在那里。通过“召集乘坐”上车的伙伴，在玩家下车后尝试安全下车并恢复此前跟随状态。新的跟随／等待或营地分工命令会取消未完成的登乘，并要求已就座的伙伴安全离座。战斗、救援、死亡、变形、载具移除或区块卸载会中断未完成的登乘任务。

乘坐不会改变关系、好感、跟随开关、营地分工或物品。已完成的乘客关系正常存档，未完成的选座和座位预留不存档。

## 其他模组与双人马

未专门适配的多座载具，只要使用正常乘客机制并接纳 NPC，就可以尝试加入。玩家已经正常骑上的驯服双人马也可使用“召集乘坐”。模组若只允许玩家、使用独立座位实体或需要特殊权限，则仍可能需要专门适配；不强制绕过它的限制。

Superb Warfare 已实测 `0.8.9.1-hotfix` 的 M1A2 和快艇。通用双人马目前验证了允许／拒绝 NPC 的乘客接口，不代表所有双人马模组的发布版都已实测。

整合包可以通过实体类型标签 `changed_synergy:companion_seats`，允许对未知载具使用手动指定。数据包示例文件：`data/changed_synergy/tags/entity_types/companion_seats.json`：

```json
{
  "replace": false,
  "values": [
    "example_mod:passenger_vehicle"
  ]
}
```

请替换示例 ID。此标签允许选择目标，不会创造空位或解除原模组的 NPC 乘坐限制。通用接入也不能保证所有模组的乘坐姿势、镜头或武器槽位都正确。

## 配置

| 配置项 | 默认 | 效果 |
| --- | --- | --- |
| `RELATIONSHIPS.CompanionSeating` | `true` | 允许手动指定座位；关闭后取消未完成的登乘，仍可安全下座。 |
| `RELATIONSHIPS.CompanionRallyBoarding` | `true` | 允许批量召集，需要同时开启伙伴乘坐。 |
